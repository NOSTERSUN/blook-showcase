📁 BLOOK LIVING — โฟลเดอร์รูปแกลเลอรี (สำหรับหน้า gallery.html)
================================================================

โฟลเดอร์นี้เก็บ "เฉพาะรูปที่แสดงบนหน้าแกลเลอรี" ของเว็บ
  https://blookliving.com/gallery.html
แยกออกมาให้บริหารจัดการง่าย ไม่ปนกับรูปสินค้าหน้าอื่น

----------------------------------------------------------------
➕ วิธีเพิ่มรูปใหม่
----------------------------------------------------------------
1) วางไฟล์รูป (.jpg หรือ .png) ลงในโฟลเดอร์นี้
   ตั้งชื่อสื่อความหมาย เช่น  sofa-05.jpg  หรือ  lifestyle-01.jpg
2) เปิดไฟล์  gallery.html  (อยู่โฟลเดอร์หลักของเว็บ)
3) หาบล็อก   const ALL_GALLERY=[ ... ]
4) เพิ่มบรรทัด   'assets/gallery/ชื่อไฟล์ของคุณ.jpg',
5) บันทึก แล้วอัปขึ้นเว็บ:
      git add -A
      git commit -m "gallery: เพิ่มรูปใหม่"
      git push origin main

----------------------------------------------------------------
➖ วิธีเอารูปออกจากเว็บ
----------------------------------------------------------------
- ลบบรรทัดของรูปนั้นออกจากลิสต์ ALL_GALLERY ในไฟล์ gallery.html
- (ถ้าต้องการ) ลบไฟล์รูปออกจากโฟลเดอร์นี้ด้วย เพื่อให้โฟลเดอร์สะอาด

----------------------------------------------------------------
📝 หมายเหตุ
----------------------------------------------------------------
- รูปในโฟลเดอร์นี้เป็น "สำเนา" คนละชุดกับรูปสินค้าหน้าอื่น
  → แก้/ลบที่นี่ ไม่กระทบหน้า index หรือบทความ
- รูปแนวตั้ง/แนวนอนได้หมด เลย์เอาต์เป็น masonry จัดให้อัตโนมัติ
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษ/ตัวเลข เลี่ยงเว้นวรรคและอักขระพิเศษ
- ลำดับการแสดงบนเว็บ = ลำดับในลิสต์ ALL_GALLERY

(ไฟล์รูปชุดเริ่มต้น: sofa, sofa-3d, pillow, diffuser-250, diffuser-50, gift)
